# The Self-Checkout Is Judging You

One funny line in the voice of a smug self-checkout machine, written for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-the-self-checkout-is-judging-you-b71130d6).

> Twelve yoghurts, one banana, zero shame detected — please place your dignity in the bagging area.

`main.py` (Python 3.13, stdlib only) prints the line and writes it to `/output/entry.txt`.
